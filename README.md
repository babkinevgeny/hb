# Хоббит: Нежданное путешествие

Личный мобильный квест на 20 октября 2026. Статический сайт без бэкенда и npm-зависимостей. Визуальный мир: круглая дверь, вечерний Шир, письмо на пергаменте и карта странника. Обложка — оригинальная AI-иллюстрация, не кадр из фильма.

## Запуск

Node 22+, Python 3 для локального сервера:

```
npm test
npm run build
npm run dev
```

Открыть http://localhost:4173. Не открывать index.html через file://: главы загружаются через fetch. Сборка копирует приложение и графику в dist.

## Сюжет и отсутствие спойлеров

Героиня получает письмо Серого Странника и собирает восемь слов утраченной страницы. Типы заданий: акростих, буквенный шифр, поиск листа, три вертикальных свитка, неверные ярлыки, анаграмма лакомства и имя привратника и сборка финальной фразы.

Каждая глава проходит две стадии:

1. **Закрытое послание:** видны только атмосферный текст, загадка и постепенные подсказки. Адрес, координатная метка новой остановки и номер заказа не выводятся в DOM. Фэнтезийные отправители и край Дорвинион названы в приглашениях по сюжету.
2. **Печать разгадана:** появляются адрес и поручение на месте. После визита кнопка подтверждения выдаёт слово в инвентарь и открывает следующую загадку. Приглашения называют эльфийских дарителей; после разгадки указаны хозяева текущего адреса.

Названия сюрпризов (адвент-календарь, Viticulture, косынка) не выводятся ни в истории, ни в инвентаре, ни в грамоте. Moscovitas названы как открытое поручение: подкрепиться и купить коробочку. Сюрприз раскрывается в реальной встрече. Номер заказа выдаётся после решения загадки Singularu; он публичен по разрешению владельца. Сам факт получения заказа сайт не проверяет.

`quest.json` редактируется без переписывания приложения: `prologue`, `prologueSignature`, `intro`; затем главы по порядку с полями `title`, `story`, `riddle`, `answers`, `hints`, `arrival`, `afterVisit` (необязательно), `place`, `coordinates` ([долгота, широта] WGS84), `reward` (слово страницы), `enabled`. Грамота: `claimOrder`, `orderNumber`. Финал: `journey.destination`, `journey.message`. Направление пока не выбрано. IKEA исключена.

Проверка ответа игнорирует регистр, пунктуацию, различие е/ё и лишние пробелы; допустимые варианты нужно перечислять в `answers`. Следите, чтобы текст загадки и подсказок не называл подарок, хозяев или адрес. Ответы и координаты доступны в исходниках: загадки управляют игровой подачей, а не защищают публичные данные.

## Прогресс и меню хранителя

Прогресс и частичные решения сохраняются в localStorage этого браузера. Прикрепление фото и фотожурнал убраны. Существующая старая база фотографий автоматически не удаляется. Пять быстрых нажатий на ✥ открывают меню: пропуск главы или начало истории заново с подтверждением. Сброс очищает только прогресс квеста и загадок. Анимации учитывают prefers-reduced-motion.

## Карта

`oviedo-map.svg` — геометрия улиц и парков OpenStreetMap (© OpenStreetMap contributors, ODbL, https://www.openstreetmap.org/copyright), полученная 18.10.2026 из общих городских фрагментов через API map. Границы: -5.854,43.349,-5.837,43.375. Собственные цвета и стилизация. При изменении `map.bounds` SVG нужно пересоздать в той же проекции.

Дом и обе встречи с друзьями включены с адресами и координатами по явному разрешению владельца. Точка дома соответствует общему входу 14/16 из OpenStreetMap. Пунктир соединяет открытые остановки и не является пешеходной навигацией. Сначала виден только дом; новая точка появляется только после решения относящейся к ней загадки.

## GitHub Pages

Settings → Pages → Source: GitHub Actions. Workflow `.github/workflows/pages.yml` тестирует, собирает `dist` и публикует push в `main` либо ручной запуск. Относительные URL поддерживают `/hb/`. Адрес: https://babkinevgeny.github.io/hb/ .

Перед праздником нужно пройти все задания на целевом телефоне, согласовать встречи и ресторан, проверить часы работы. Контент ещё можно менять, но порядок/id глав желательно зафиксировать до начала прохождения.

## Интерактивные артефакты и подготовка спутника

Главы `jewel`, `sweet`, `winter` используют конфигурацию `puzzle`:

- `constellation`: `signatures` связывает отправителей с небесными знаками, `groups` задаёт созвездия, `sequence` — верный порядок. На воске показаны зеркальные отражения небесных знаков; среди девяти созвездий есть отражённые, повёрнутые и дополненные двойники. `orderClue` задаёт порядок отправителей, `mirrorClue` объясняет отражение образным языком. Ошибка сбрасывает цепочку только после трёх выборов: промежуточная правильность не раскрывается. Повтор одного знака не считается вторым выбором. `revision` сбрасывает устаревшую частичную цепочку без удаления другого прогресса. Грамота открывается только после всей цепочки.
- `map`: девять фрагментов квадратного `map-fragment.svg`; `initial` — перестановка индексов 0–8. Два нажатия меняют фрагменты местами; перетаскивания и таймера нет. Карта взята из той же географической основы, маленький знак отмечает остановку.
- `cipher`: `message` выводится рунами; жена видит послание, муж получает только алфавит. Текстовый ответ проверяется по `answers`. Это собственный игровой шифр, а не настоящий эльфийский алфавит.

Ход созвездий и раскладка карты сохраняются в `hobbit-interactive-v1` в localStorage. После решения сохраняется обычная стадия `solved`; визит подтверждается отдельно. Для просмотра новых испытаний в уже пройденной игре откройте меню хранителя и выберите «Начать историю заново».

**Распечатка больше не нужна.** Седьмая глава использует экранный «Камень переводчика»: игрок выбирает руну в послании, сверяет её с гномьим алфавитом на этом же экране и назначает букву. Все одинаковые знаки заполняются вместе. Перевод можно исправлять и очищать; проверяется целиком, без немедленных подсказок о правильности букв. Частичные назначения сохраняются локально. `keeper-key.html` и алфавит в меню хранителя оставлены необязательным запасным справочником.

`keeper-key.html` генерируется из того же определения знаков, что и послание: `node scripts/generate-key.js`. Генератор также вызывается при сборке. Если изменяете алфавит, обновите и сгенерированный файл перед коммитом.

Оформление грамоты использует отдельные SVG-созвездия с математически точными отражениями и CSS-печати. `paper-grain.svg` даёт фактуру пергамента, `storybook-background.jpg` — оригинальный AI-декор с фонарём, компасом и лесной листвой. Текст и интерактивные знаки остаются отдельными элементами, а не частью иллюстрации. Карта и гномий шифр при этом не меняются.

## Поющие ворота Дорвиниона

У главы `company` тип `puzzle: melody`: восемь неподвижных листьев, включая два полутона, и три печати на 4, 8 и 12 нот. Каждый раунд продолжает предыдущий. `notes` задаёт имена и частоты, `sequence` — индексы нот с нуля, `rounds` — длины раундов, `rhythm` — относительную длительность шагов, `tempoMs` и `slowTempoMs` — обычный и медленный темп. Это оригинальный напев, а не запись или переложение музыки из фильмов.

Подсветка и номера листьев сопровождают звук; доступны медленное прослушивание и выключение звука. Прослушивание блокирует ввод. Ошибка сбрасывает только текущую попытку; открытые печати сохраняются. Повторы не ограничены, таймера ответа нет. После третьего раунда ворота открываются и появляется приглашение от Димитриона и Наделиэль с адресом. В `hobbit-interactive-v1` сохраняются раунд, прослушивание и текущая попытка. Звук синтезируется локально через Web Audio после нажатия пользователя. Переход между главами или открытие подсказки останавливает таймеры и закрывает аудиоконтекст.

## Ужин и последняя совместная печать

Глава `feast` открывает приглашение в Tierra Astur без ввода слова. Адрес появляется после нажатия приглашения. Кнопка «Мы готовы к новой дороге» предназначена для нажатия после ужина и открывает финал. Два кольца соединяют золотую дорогу от дома до гор; затем два участника одновременно удерживают каждый свою печать две секунды. На сенсорном экране нужен мультитач, на клавиатуре — A + L. Отпускание любой печати сбрасывает удержание. Повороты сохраняются локально, удержание — нет. Вторая карта появляется только после совместного действия; её направление и текст по-прежнему задаются в `journey` в quest.json.

Приглашение к ужину (`invitation.js`) проявляется теплом фонаря: четыре строки из `chapters[].puzzle.verse` открываются строго по порядку при удержании фонаря у текущей строки. Есть кнопка для клавиатуры и удобства на телефоне. Проявленные строки сохраняются локально. Последняя строка — подсказка про яблочный напиток; адрес появляется только после всего стихотворения. Финальные кольца собирают дом с сердцем и тропинкой — символ общего дома, любви и путешествий.

## Фоновая музыка

Кнопка внизу экрана включает/выключает предоставленный пользователем файл `concerning-hobbits.mp3` (Howard Shore — Concerning Hobbits). Используется обычный HTML Audio без видео и внешних сервисов. Файл загружается только после включения. Запись зациклена; при паузе позиция сохраняется. Громкость по умолчанию 25%, на iPhone регулируется системными кнопками. Во время нерешённой главы с листьями фон на паузе; после решения возобновляется, если пользователь его не выключил. При перезагрузке требуется новое включение.


Гномье оформление: `dwarf-tablet.jpg` — оригинальная AI-иллюстрация из built-in image_gen, использованная как каменная рамка и фактура плиток. Знаки поверх неё — воспроизводимые SVG, одинаковые в послании и справочнике. Промпт и сведения об ассете: `dwarf-art.md`.

## Сундучок второго завтрака и ожившая страница

`breakfast.puzzle` типа `letter-lock`: `alphabet` — 27 букв языка местных земель с Ñ, `codes` — номера букв комбинации с единицы, `initial` — начальные положения колёсиков с нуля, Разделители между словами на колёсиках не показываются. Колёсики вращаются кнопками, нажатием буквы и вертикальным свайпом. Проверяется вся комбинация; после успеха крышка открывается. Положения колёсиков сохраняются локально.

`forest.puzzle` типа `living-leaf`: игрок проводит по средней жилке снизу вверх, затем по подсвеченным боковым от центра к краю. Точки пути проверяются последовательно с допуском для пальца. Неудачный незавершённый штрих можно повторить, готовые жилки остаются. Есть кнопка для клавиатуры и альтернативного прохождения. После девяти жилок отпечаток становится осенним листом-закладкой. `revision` каждого интерактива сбрасывает только его устаревшее частичное решение.

Обложка `hero-umka.jpg` — версия исходной иллюстрации с собакой Умкой в дорожном плаще, созданная встроенным image_gen по предоставленным фотографиям. Фотографии-референсы не публикуются. Промпт и роли изображений описаны в `umka-art.md`. На телефоне отдельное кадрирование оставляет собаку под текстом.

Текущая обложка — `hero-umka-oviedo.jpg`: к Умке и круглой двери добавлена фантазийная панорама Овьедо с кафедральным собором у реки. На мобильном экране кадрирование показывает и собаку, и город. Это художественная композиция, а не точная география города. Промпт второй редакции добавлен в `umka-art.md`.

Мобильная вёрстка переводчика: декоративная каменная картинка используется только в шапке с сохранением пропорций; остальная панель не растягивает её. Длинные слова из рун остаются одной строкой, алфавит раскрывается по требованию. После решения любой главы прокрутка ведёт прямо к «Теперь ты знаешь путь». Колёсики замка анимируются в направлении вращения (кроме reduced-motion), разделителя после второй буквы нет. Финальная дорожка собрана flex-элементами и не переносит знак вопроса.
