# Хоббит: Нежданное путешествие

Личный мобильный квест на 20 октября 2026. Статический сайт без бэкенда и npm-зависимостей. Визуальный мир: круглая дверь, вечерний Шир, письмо на пергаменте и карта странника. Обложка — оригинальная AI-иллюстрация, не кадр из фильма.

## Запуск

Node 22+, Python 3 для локального сервера:

```
npm test
npm run build
npm run dev
```

Открыть http://localhost:4173. Не открывать index.html через file://: главы загружаются через fetch. Сборка копирует приложение и графику в dist.

## Сюжет и отсутствие спойлеров

Героиня получает письмо Серого Странника и собирает восемь слов утраченной страницы. Типы заданий: акростих, буквенный шифр, поиск листа и фотоохота, три вертикальных свитка, неверные ярлыки, анаграмма лакомства и имя привратника и сборка финальной фразы.

Каждая глава проходит две стадии:

1. **Закрытое послание:** видны только атмосферный текст, загадка и постепенные подсказки. Адрес, координатная метка новой остановки и номер заказа не выводятся в DOM. Фэнтезийные отправители и край Дорвинион названы в приглашениях по сюжету.
2. **Печать разгадана:** появляются адрес и поручение на месте. После визита кнопка подтверждения выдаёт слово в инвентарь и открывает следующую загадку. Приглашения называют эльфийских дарителей; после разгадки указаны хозяева текущего адреса.

Названия сюрпризов (адвент-календарь, Viticulture, косынка) не выводятся ни в истории, ни в инвентаре, ни в грамоте. Moscovitas названы как открытое поручение: подкрепиться и купить коробочку. Сюрприз раскрывается в реальной встрече. Номер заказа выдаётся после решения загадки Singularu; он публичен по разрешению владельца. Сам факт получения заказа сайт не проверяет.

`quest.json` редактируется без переписывания приложения: `prologue`, `prologueSignature`, `intro`; затем главы по порядку с полями `title`, `story`, `riddle`, `answers`, `hints`, `arrival`, `afterVisit` (необязательно), `place`, `coordinates` ([долгота, широта] WGS84), `reward` (слово страницы), `enabled`. Грамота: `claimOrder`, `orderNumber`. Финал: `journey.destination`, `journey.message`. Направление пока не выбрано. IKEA исключена.

Проверка ответа игнорирует регистр, пунктуацию, различие е/ё и лишние пробелы; допустимые варианты нужно перечислять в `answers`. Следите, чтобы текст загадки и подсказок не называл подарок, хозяев или адрес. Ответы и координаты доступны в исходниках: загадки управляют игровой подачей, а не защищают публичные данные.

## Хранение

Новая история использует `hobbit-quest-story-v2` в localStorage. Прогресс старой версии оставлен отдельно, но не импортируется: механика и ответы изменились. Уже сохранённые фото не удаляются.

Оригиналы JPEG/PNG/WebP до 12 МБ хранятся в IndexedDB (`hobbit-journal`) только в этом браузере/профиле/на этом устройстве. У каждого снимка есть скачивание и удаление. Фото необязательны, не проверяют выполнение задания. Нет загрузки на сервер, синхронизации или резервного копирования. Очистка данных браузера удалит журнал. Приватный режим и нехватка памяти могут мешать сохранению; приложение показывает сообщение. Офлайн-режим не гарантируется. Google Fonts при недоступности заменяются системными шрифтами.

## Меню хранителя

Пять быстрых нажатий на ✥ внизу страницы открывают служебное меню: пропустить текущую главу или полностью сбросить прогресс и фото с подтверждением. Это не аутентификация. Перед сбросом скачайте нужные снимки. Анимации учитывают prefers-reduced-motion.

## Карта

`oviedo-map.svg` — геометрия улиц и парков OpenStreetMap (© OpenStreetMap contributors, ODbL, https://www.openstreetmap.org/copyright), полученная 18.10.2026 из общих городских фрагментов через API map. Границы: -5.854,43.349,-5.837,43.375. Собственные цвета и стилизация. При изменении `map.bounds` SVG нужно пересоздать в той же проекции.

Дом и обе встречи с друзьями включены с адресами и координатами по явному разрешению владельца. Точка дома соответствует общему входу 14/16 из OpenStreetMap. Пунктир соединяет открытые остановки и не является пешеходной навигацией. Сначала виден только дом; новая точка появляется только после решения относящейся к ней загадки.

## GitHub Pages

Settings → Pages → Source: GitHub Actions. Workflow `.github/workflows/pages.yml` тестирует, собирает `dist` и публикует push в `main` либо ручной запуск. Относительные URL поддерживают `/hb/`. Адрес: https://babkinevgeny.github.io/hb/ .

Перед праздником нужно пройти все задания на целевом телефоне, согласовать встречи и ресторан, проверить часы работы. Контент ещё можно менять, но порядок/id глав желательно зафиксировать до начала прохождения.

## Интерактивные артефакты и подготовка спутника

Главы `jewel`, `sweet`, `winter` используют конфигурацию `puzzle`:

- `constellation`: `signatures` связывает отправителей с небесными знаками, `groups` задаёт созвездия, `sequence` — верный порядок. На воске показаны зеркальные отражения небесных знаков; среди девяти созвездий есть отражённые, повёрнутые и дополненные двойники. `orderClue` задаёт порядок отправителей, `mirrorClue` объясняет отражение образным языком. Ошибка сбрасывает цепочку только после трёх выборов: промежуточная правильность не раскрывается. Повтор одного знака не считается вторым выбором. `revision` сбрасывает устаревшую частичную цепочку без удаления другого прогресса. Грамота открывается только после всей цепочки.
- `map`: девять фрагментов квадратного `map-fragment.svg`; `initial` — перестановка индексов 0–8. Два нажатия меняют фрагменты местами; перетаскивания и таймера нет. Карта взята из той же географической основы, маленький знак отмечает остановку.
- `cipher`: `message` выводится рунами; жена видит послание, муж получает только алфавит. Текстовый ответ проверяется по `answers`. Это собственный игровой шифр, а не настоящий эльфийский алфавит.

Ход созвездий и раскладка карты сохраняются в `hobbit-interactive-v1` в localStorage. После решения сохраняется обычная стадия `solved`; визит подтверждается отдельно. Для просмотра новых испытаний в уже пройденной игре откройте меню хранителя и выберите «Начать сначала · фотографии сохранить». Полный сброс с удалением фото остаётся отдельной кнопкой.

**Подготовить нужно только один лист:** открыть `/keeper-key.html` и нажать «Распечатать / сохранить PDF». Лист рассчитан на A4, чёрно-белая печать подходит. Сложить и взять с собой; достать на седьмой главе. Не показывать героине: нужно описывать друг другу знаки. Сами друзья ничего не печатают.

Ключ полностью автономный: его можно скачать как HTML через меню хранителя, открыть без сети и распечатать позже. Запасной алфавит встроен в меню хранителя (5 быстрых нажатий на ✥ → «Ключ спутника»). Сохраните его заранее либо открывайте на втором телефоне; на одном телефоне можно передавать экран друг другу.

`keeper-key.html` генерируется из того же определения знаков, что и послание: `node scripts/generate-key.js`. Генератор также вызывается при сборке. Если изменяете алфавит, обновите и сгенерированный файл перед коммитом.

Оформление грамоты использует отдельные SVG-созвездия с математически точными отражениями и CSS-печати. `paper-grain.svg` даёт фактуру пергамента, `storybook-background.jpg` — оригинальный AI-декор с фонарём, компасом и лесной листвой. Текст и интерактивные знаки остаются отдельными элементами, а не частью иллюстрации. Карта и совместный шифр при этом не меняются.

## Поющие ворота Дорвиниона

У главы `company` тип `puzzle: melody`: восемь неподвижных листьев, включая два полутона, и три печати на 4, 8 и 12 нот. Каждый раунд продолжает предыдущий. `notes` задаёт имена и частоты, `sequence` — индексы нот с нуля, `rounds` — длины раундов, `rhythm` — относительную длительность шагов, `tempoMs` и `slowTempoMs` — обычный и медленный темп. Это оригинальный напев, а не запись или переложение музыки из фильмов.

Подсветка и номера листьев сопровождают звук; доступны медленное прослушивание и выключение звука. Прослушивание блокирует ввод. Ошибка сбрасывает только текущую попытку; открытые печати сохраняются. Повторы не ограничены, таймера ответа нет. После третьего раунда ворота открываются и появляется приглашение от Димитриона и Наделиэль с адресом. В `hobbit-interactive-v1` сохраняются раунд, прослушивание и текущая попытка. Звук синтезируется локально через Web Audio после нажатия пользователя. Переход между главами или открытие подсказки останавливает таймеры и закрывает аудиоконтекст.
