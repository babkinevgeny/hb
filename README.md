# Хоббит: Нежданное путешествие

Мобильный квест для именинницы и мужа, 20 октября 2026. Статическое приложение, без зависимостей и бэкенда. Вдохновлено трилогией «Хоббит»; иллюстрации, музыка и кадры фильмов не используются.

## Запуск и проверка

Node 22+, Python 3 для локального сервера:

```
npm test
npm run build
npm run dev
```

Открыть http://localhost:4173. Не открывать index.html через file://: конфигурация загружается через fetch.

## Контент

Редактируйте `quest.json`: порядок `chapters` определяет маршрут. `enabled: false` исключает остановку (IKEA и Parque de Invierno изначально выключены). `story`, `riddle`, `answers` (массив допустимых точных ответов), `hints`, `reward`, `place`, `x/y` (проценты на художественной схеме) полностью управляют главой. Проверка игнорирует регистр, пунктуацию, пробелы и различие е/ё. Это схема, не навигационная карта.

Все остановки и загадки — placeholders. Друзья, подарки и бронирования не подтверждены. Перед праздником отредактируйте тексты, проверьте адреса/доступность остановок и поставьте `draft: false`. В `journey.destination` укажите направление второй карты, когда оно станет известно; `null` оставляет тайну. `journey.message` — финальное послание. Не размещайте билеты, адрес дома, персональные данные или другие секреты в публичном репозитории. Ответы также видны в исходниках.

## Хранение

Прогресс хранится в localStorage, оригиналы фото — в IndexedDB, только в этом браузере/профиле/на этом устройстве. Фото необязательны и не проверяют прохождение. У каждого снимка есть «Скачать» и «Удалить». Нет загрузки на сервер, синхронизации или резервного копирования. Очистка данных сайта и приватный режим могут удалить данные. При запрете/переполнении хранилища приложение показывает сообщение. При смене браузера, домена или устройства прогресс не переносится. Офлайн-режим не гарантируется: загрузите приложение при наличии сети. Шрифты загружаются из Google Fonts, без сети используются системные.

## Служебное меню

Пять быстрых нажатий на ✥ внизу страницы открывают меню мужа: завершение текущей непройденной главы и полный сброс с подтверждением, включая фото. Это удобство, не аутентификация. Финал открывается после всех включённых глав, вторая карта разворачивается отдельной кнопкой. Поддерживается prefers-reduced-motion.

## GitHub Pages

В Settings → Pages выберите Source: GitHub Actions. Workflow `.github/workflows/pages.yml` тестирует, собирает `dist` и публикует push в `main` либо ручной запуск. Все URL относительные: приложение работает по `/hb/`, без framework basePath. Ожидаемый адрес после успешного деплоя: https://babkinevgeny.github.io/hb/ . Сам факт наличия workflow не означает, что Pages включён.

Перед праздником пройдите квест на целевом телефоне: неверный/верный ответ, подсказки, обновление страницы, фото и скачивание, служебный сброс, пропуск всех глав и финал. В iOS и Android доступность камеры/выбора файлов зависит от браузера. Конфигурацию желательно зафиксировать до старта: изменение порядка/id глав может сбросить последующую часть сохранённого прогресса.
