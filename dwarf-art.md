# Камень переводчика

Создано встроенным image_gen, не CLI. Итоговый оптимизированный файл: `dwarf-tablet.jpg`. Декоративные руны находятся на обрамлении; игровые знаки накладываются кодом для точного совпадения с алфавитом.

## Промпт

Use case: stylized-concept. Generate a production web game background asset, portrait 1024x1536. A magnificent ancient dwarven rune translator stone tablet, straight-on orthographic top view. Dark blue-grey basalt, hammered bronze bevels, intricate angular dwarven knotwork along the four borders, tiny amber gemstones and warm forge glow in corners, worn stone chips, cinematic tactile fantasy craft inspired by a mountain kingdom. Broad central 75% of the tablet is EMPTY flat dark stone with low-contrast grain, to place crisp interactive rune UI over it. Decorative deeply engraved angular runic marks ONLY along outer border. No readable text, no Latin letters, no UI, no actual buttons. Elegant high detail, high contrast edge carvings, restrained ember glow, no people, no skulls. Must work as a vertically stretching background on mobile.
